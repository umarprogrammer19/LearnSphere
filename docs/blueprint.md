# **App Name**: LearnSphere

## Core Features:

- Firebase Phone Authentication: Implement phone number authentication using Firebase OTP for secure user login.
- Role-Based Profile Setup (Student): Enable students to create profiles by providing board, class, and subject information.
- Role-Based Profile Setup (Tutor): Allow tutors to create profiles detailing their qualifications, subjects taught, hourly rate, and available time slots.
- Homepage with Map and Tutor Cards: Show a Google Maps view alongside a tutor list, displaying nearby tutors.
- Tutor Details and Booking: Provide a page to view detailed tutor information and book sessions.
- Mock Payment Confirmation: After booking, display a placeholder payment confirmation screen.

## Style Guidelines:

- Background color: Light, desaturated purple (#F8FAFC). This creates a calm, clean background, fitting the EdTech theme. It has very little saturation, allowing the other colors to stand out.  
- Primary color: Vibrant blue (#4A6CF7) to convey trust and knowledge.
- Accent color: Sunny yellow (#FFCE4E) to highlight calls to action.
- Headline font: 'Space Grotesk' sans-serif for a modern tech feel, suited for short bursts of text.
- Body font: 'Inter' sans-serif to ensure excellent readability and a neutral appearance. If the text becomes more substantial in a future release, this choice is appropriate.
- Use a consistent style of outlined icons focused on education and location.
- Glass cards and rounded UI elements create depth and visual appeal, enhancing the modern look.
- Incorporate subtle transitions on hover and tap to enhance user experience without being distracting.
